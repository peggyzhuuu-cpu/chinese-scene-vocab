# 汉语场景词汇通 | Chinese Scene Vocab
## 📌 项目简介
**「汉语场景词汇通」** 是一款面向汉语作为第二语言（CSL）学习者的移动端应用。
项目以真实生活场景为核心，结合实际交际需求，围绕 **「餐厅就餐、商场购物、公共交通、医院就医、校园学习、酒店旅行」** 六大高频生活场景，提供词汇查询、图文音学习、场景对话、词汇自测和趣味游戏等核心功能。

重点解决传统词汇学习中 **“记住了词汇，但在真实场景中不会使用”** 的痛点，帮助学习者建立词汇与生活场景之间的强关联。

## 💡 产品设计思路

项目采用 **「场景 → 词汇 → 对话 → 自测 → 游戏」** 的全闭环学习路径：
场景认知 ➔ 词汇理解 ➔ 场景应用 ➔ 自我检测 ➔ 趣味巩固
用户既可以按生活场景逐级学习，也可以通过多维度搜索快速定位目标词汇，在双语对话中掌握用法，最后通过自测与看图说词游戏巩固记忆。
